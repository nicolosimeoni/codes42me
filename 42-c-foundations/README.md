# 42 C Foundations

A collection of three foundational C projects from the 42 curriculum, brought together to explore how memory management and input/output work at a low level.

| Project | Purpose |
| --- | --- |
| **libft** | Utility functions for strings, memory and linked lists. |
| **ft_printf** | Formatted output using variadic arguments. |
| **get_next_line** | Buffered, line-by-line reading from file descriptors. |

Together, these projects cover reusable utilities, writing output and reading input. They share one repository because they form a small, coherent foundation in C. `ft_printf` uses `libft`; `get_next_line` is independent.
